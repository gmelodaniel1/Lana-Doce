# 03: Tela de Conclusão de Episódio e Transição Contínua de Campanha

**What to build:**
Ao chegar no último nó de um episódio (ex: `ep1_end_01`), em vez de o jogo parar, é exibida uma tela estilizada de "Fim de Episódio", mostrando o balanço das afinidades conquistadas com cada pesquisador (ex: Gabs +5, Letícia +5, Will +5), feedback da Profª Kátia, e um botão de transição fluida para iniciar o próximo episódio herdando as afinidades e histórico acumulados.

**Blocked by:** 02: Menu Principal e Seletor de Episódios (Title Screen & Episode Hub)

**Status:** done

- [x] Tela de resumo pós-episódio com contabilidade de LOM ganho/perdido por personagem
- [x] Mensagem avaliativa personalizada com base no saldo de afinidade
- [x] Botão de continuação que carrega o episódio seguinte preservando afinidades acumuladas
- [x] Botão de retorno ao Menu Principal com status de episódio concluído
